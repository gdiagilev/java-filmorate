# java-filmorate
Проект Filmorate
Схема базы данных:
![ER-диаграмма](src/docs/images/ERD.png)

Описание базы данных:
База данных предназначена для хранения информации о пользователях, фильмах и их взаимодействии.

Основные сущности:

- users — пользователи приложения
Хранит учётные данные, имя и дату рождения.

- films — фильмы
Содержит основную информацию о фильме и ссылку на рейтинг MPA.

- mpa — справочник возрастных рейтингов
Используется для классификации фильмов по возрастным ограничениям.

- genres — справочник жанров фильмов.

Связующие таблицы:

- film_genres — связь многие-ко-многим между фильмами и жанрами
Один фильм может иметь несколько жанров, и один жанр может относиться к разным фильмам.

- film_likes — лайки фильмов пользователями
Используется для подсчёта популярности фильмов.

- friendships — социальные связи между пользователями
Хранит заявки в друзья (PENDING) и подтверждённые дружбы (CONFIRMED).

Примеры основных SQL-запросов:

Создание пользователя:

INSERT INTO users (email, login, name, birthday)
VALUES ('user@mail.ru', 'user123', 'Ivan', '1995-05-20');

Получение всех фильмов с рейтингом MPA:

SELECT f.id, f.name, m.name AS mpa_rating
FROM films f
JOIN mpa m ON f.mpa_id = m.id;

Поставить лайк фильму:

INSERT INTO film_likes (film_id, user_id)
VALUES (1, 5);
